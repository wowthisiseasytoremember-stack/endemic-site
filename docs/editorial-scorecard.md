# Editorial Quality Scorecard

Every generated article must be evaluated against this 100-point rubric. A score of 90 or above is required for publication.

## 100-Point Scoring Rubric

| Category | Points | Description |
|---|---:|---|
| **Accuracy and sourcing** | 25 | All factual claims are supported by real, linked sources. |
| **Readability and editorial quality** | 20 | Tone matches the Brand Constitution. Not SEO slop. |
| **Information architecture** | 15 | Clear structure using an approved archetype. No skipped headings. |
| **Brand and visual composition** | 15 | Correct use of BentoGrid, no identical card walls. |
| **Component appropriateness** | 10 | Uses the right MDX components for the intent. |
| **Accessibility and semantics** | 10 | Alt text on all images, proper contrast. |
| **Metadata and internal linking** | 5 | Frontmatter is valid, internal links do not 404. |
| **Total** | **100** | |

### Release Thresholds
- **90–100:** Publishable
- **80–89:** Minor editorial revision
- **70–79:** Structural revision required
- **Below 70:** Return to planning stage

## Automatic Rejection Conditions
A high numerical score **cannot** override these conditions. Any of the following triggers an immediate rejection:
1. Fabricated source
2. Fabricated quotation
3. Invented internal URL
4. Missing disclosure for uncertainty
5. Dangerous husbandry or safety instruction
6. Invalid MDX
7. Unlicensed or unattributed image
8. Multiple H1 elements
9. Critical accessibility failure (e.g., missing alt text on a functional image)
10. Presence of banned design patterns (e.g. side-stripe borders, oversized radii)
